# Coalign website

Public deployment assets for https://coalign.github.io/.

The development repository is maintained separately. This repository contains the static website and applicable asset licenses. GitHub Pages publishes the main branch.

Contact actions open the tree-themed updates page. Because Pages cannot run the local signup database, the published form opens an email request to Coalign; visitors must send the email to request updates. It does not claim to save an address automatically. Local SQLite storage and CSV exports remain private and are not deployed.
